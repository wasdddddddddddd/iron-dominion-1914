# AI 军事战略完整逻辑（Iron & Dominion 1914）

> 本文档描述 `js/ai/ai_controller.js` + `js/ai/ai_strategy.js` 中 AI 军事决策的全部机制，按"战略 → 战役 → 战术 → 防御 → 生产"五层说明。2026-08-05 更新。

---

## 一、战略层（国家角度：打谁、打哪个方向）

### 1.1 主敌判定（mainEnemy）

- **历史宿敌优先**：德→法/俄，俄→德/奥匈，奥匈→俄/塞/意，法→德……（HISTORICAL_RIVALS 表）
- 从"正在交战的宿敌"中选**兵力最大的**为主敌
- 特殊：**史丽芬阶段**（比利时/卢森堡未被彻底征服）德国主敌强制 = 比利时，不看兵力
- 例外：**本土损失 > 25%** 时取消史丽芬强制 → 先回防

### 1.2 史丽芬计划（德国专属，国家硬目标）

- 判定"国家被灭"：首都沦陷 / 已投降 / 无任何存活城市
- **比利时未灭**：比利时权重 ×6.0、卢森堡 ×4.0、法国 ×0.8、其他 ×0.3
- **卢森堡未灭**：卢森堡 ×5.0、比利时 ×3.0
- **两国皆灭**：法国 ×3.0，全力南下
- 权重转"硬性加分"：权重≥5 → +600 分、≥3 → +350、≥1.5 → +150、<0.5 → **-120**
- **硬目标征召**：只征召"前 60% 的组"（按大小排序）+ 组成员**多数不在德国东部**（rx>11 为东，普鲁士组跳过硬目标去东线）
- 硬目标过滤时**保留收复城市 + 中立城市**（边境沦陷 → 回防优先于入侵）

### 1.3 普鲁士兵打俄国（德国东部定向）

- 德国中部以东（lon>10）**无任务单位**：每帧直接指派**最近的俄国城市**（不依赖组分配）
- 目标校准：东部单位（rx>11）若目标不是 RUSSIA 城市 → 清除任务重新指派
- 东线集团军战区：`_theater=EASTERN`，只攻该战区城市

### 1.4 战区分兵（generateTheaterPlan）

- 战区：WESTERN（德法比荷英）、EASTERN（德俄奥）
- 战区优先级 = 历史宿敌加权（宿敌所在战区 ×2.5）+ 敌方兵力密度
- 按 priority 比例分配组的 `targetPercent`（组循环按配额分派战区）
- 次要敌人（如土耳其对俄国）战区 ×0.4 降权

### 1.5 敌方城市评分（先清前线再深入）

- **前线距离**（动态）：到最近"己方控制城市"的距离（含占领的敌城，不写死国界）
- 距边境 <2° → +120；2-4° → +60；4-6° → +20；>6°（腹地）→ **-30 扣分**
- 首都/大城仅当离前线近才加分（<3° +80/+30，>6° 不加）
- **软柿子加成**：守军 0 且 <4° → +90；守军≤1 且 <3° → +60；守军≤2 且 <2° → +30
- 低血量 +30~50；守军多扣分（-10/个）
- 收复城市（己方沦陷）：首都 400 / 大城 220 / 农城 180 / 普通 150 + 距己方近加分 + 家门口 +100
- 中立城市：首都 100 / 大城 70 / 普通 55 + 距己方控制区近加分

## 二、战役层（范围角度：用多少兵力打）

### 2.1 兵力门槛（避免送死）

| 城市等级 | 基础需求 | 火炮支援    | 守军加成     |
| ---- | ---- | ------- | -------- |
| 首都   | 10 师 | -2（8 师） | 每守军 +0.5 |
| 大城市  | 5 师  | -1（4 师） | 每守军 +0.5 |
| 小城市  | 3 师  | -1（2 师） | 每守军 +0.5 |

- 城市血量 <40% → ×0.7；<20% → ×0.5
- 中立城：1 师即可；收复城：×0.6 且不要求优势
- **已兵临城下**（<1.5° 且组 ≥ minForce×0.7）→ 直接进攻
- **前线敌军稀少**：城市 3° 内敌方 < 组兵力 → 取消门槛
- **局部优势突破**：城市 3° 内己方 ≥ 敌方（势均力敌即突破）→ 直接进攻
- **高侵略国家**（德/俄/奥匈）门槛再降 40%

### 2.2 组分配（集团化进攻）

- 单位按位置聚类成组（半径 3°），**集团军成员强制同组**（整群推进）
- 组按大小排序，大组优先选目标（允许 3 个组打同一最高优先级城市）
- 得分 = 城市分 - 距离×5 + 组大小×3；兵力不足组降权
- 目标选定后：炮兵远程 / 步兵正面 / 骑兵侧翼 / 工兵攻城

### 2.3 三阶段攻城（方案 E）

1. **CLEAR 清野**：步兵/骑兵清城市周围敌军，炮兵在城外 0.8° 远程待命
2. **SIEGE 围城**：周围敌军 ≤2 → 步兵在 0.35° 包围圈站定（包而不进），炮兵保持射程 85% 轰击
3. **ASSAULT 总攻**：城血 ≤30%（或 ≤10% 且守军<2）→ 步兵收紧到 0.15° 冲城、工兵跟进

- 援军到来（敌军>2）→ 退回 CLEAR
- **围攻超时**：同一城 150 tick 血量仍 >60% → 放弃围攻换目标（防僵持）

### 2.4 兵种行为

| 兵种        | 行为                                                            |
| --------- | ------------------------------------------------------------- |
| **步兵/山地** | 围城站 0.35°（总攻 0.15°）；交火只追目标城 3° 内敌人，同一目标交战 >40 tick 放弃缠斗（防被钓走） |
| **火炮**    | 保持射程 85%（0.57°）轰击；太远靠近、太近后撤；绝不单兵冲锋（不参与推送/集结）                  |
| **骑兵**    | 找 2.5° 内残血/炮兵/工兵绕侧翼 45° 收割；城血<25% 才冲城；否则外围 0.9° 游弋            |
| **工兵**    | 围城在 0.55° 待命专职修复；总攻才跟进进城                                      |

## 三、防御层（动态前线）

### 3.1 动态前线判定

- **前线 = 敌军单位所在方向 + 己方占领的敌城**（不写死国界）
- `getDynamicFrontlineCities`：距敌军 <3° 或距敌占城市 <2.5° 的己方/中立城市
- 打到哪哪是前线：新占敌城自动成为防线和进攻基点

### 3.2 防御部署（aiDefenseDeployment，每 20 tick）

- 城市优先级：首都 1000 + 大城 300 + 农城 150 + 工厂 + 敌军密度（近距离敌 +60/个，3° 压迫 +20/个）− 已有守军×25
- **前线判定 2.5°**（太宽会让边境城市全部留守）
- 守军需求：前线首都 3 / 大城 2 / 农城 1 / 小城 1；非前线不守（首都无威胁 1）
- **防御总兵力上限 15%**（超限自动解除多余 DEFEND_CITY 任务）
- 不征用火炮/海军；德国东部单位不参与西部防御
- **防御任务解除**：目标城 2.5° 内已无敌军 → 解除，兵力回归进攻
- 首都遇险（敌军>5 逼近）→ 优先级 9999 全城死守

### 3.3 防线系统（aiFormDefensiveLine）

- 识别动态前线省份（敌占城市 2° 内），按敌人口密度分配守军
- 己方领土纵深无威胁 → 不布防（兵力全推前线）

### 3.4 敌军主力动态防御

- 敌军密集处防御优先级 ×2（近距离 +60、3° 压迫 +20/单位）
- 10 个敌军在某城附近 → 该城防御加成 600 分，防守资源自动聚集到主攻方向

## 四、推送与移动（防呆兵机制）

### 4.1 宣战后闲置推送

- 只推**离任何敌方城市 >4°** 的深远后方单位（前线交给集团军）
- 目标 = 主敌国首都（史丽芬阶段=比利时首都）＞ 主敌国大城 ＞ 其他首都
- **火炮绝不单兵推送**；集团军成员由集团军协调

### 4.2 任务保留（关键防呆兵）

- 单位到达目标城市后，若目标仍属敌方/中立 → **保留 ATTACK 任务持续围攻**（不清除）
- 只有目标失效（城市被占/消失）才清除任务重新分配
- 围攻单位由 `aiSiegeBehavior` **每帧驱动**（阶段转移 + 各兵种行为），不会"到站即绕圈"

### 4.3 中立城市占领

- **中立判定**：无主城市 或 **未交战国家城市**（isNeutralCity——游戏里城市 owner 是国家代码，不是 null）
- 只占距己方控制城市 **3.5° 内**的中立城
- 每城派最近 1 个兵（附近有敌军派 2 个）；优先空闲单位，不抽调集团军成员，不占火炮

## 六、执行顺序（updateAI 每 tick）

1. 历史宣战（史丽芬：德→法/比/卢，**不宣荷兰**）+ 协约国参战
2. 每 50 tick 战略评估（reevaluateStrategy / evaluateStrategicSituation）
3. **普鲁士兵目标校准**（东部清西线任务 + 直接指派俄国）
4. 宣战后闲置推送（只推 >4° 深远后方，火炮除外）
5. 任务清理（保留围攻任务 / 解除失效任务 / 防御城沦陷自动清）
6. 经济 + 生产 + 外交（每国）
7. 集团军编成（每 10 tick）+ 防御单位释放（每 30 tick）
8. **aiAttackMovement**：主敌判定 → 城市评分 → 聚类分组 → 组分配目标 → 中立城直接占 → 初始就位
9. **aiSiegeBehavior**：每帧驱动围攻单位（阶段转移 + 兵种行为）
10. 防线（每 10 tick）+ 防御部署（每 20 tick）+ 紧急防御 + 应对入侵（每 5 tick）+ 战线增援（每 15 tick）
11. 撤退处理 + 战术编组 + 海军战略 + 求和评估
