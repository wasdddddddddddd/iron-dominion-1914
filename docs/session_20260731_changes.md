## 一、UI 历史沉浸化改造

### 1.1 CSS 主题系统 (`ui/theme.css`)
- 建立完整 CSS 自定义属性体系：纸张色系（羊皮纸暖色）、墨水色系（深棕）、黄铜/金色系、军绿/海军色、血锈色
- 全局纸纹背景：多层叠加（噪点 + 纸纤维 + 暖光晕），通过 `body::before` 伪元素实现
- 加载画面、国家选择界面独立主题样式
- 国家卡片：hover 态上浮阴影 + 黄铜光晕边框
- 滚动条：黄铜渐变滑块
- 选中文字：黄铜色高亮
- 所有过渡动画使用 `cubic-bezier(0.4, 0, 0.2, 1)` 纸张质感缓动

### 1.2 Canvas 主题系统 (`ui/theme.js`)
- 轻量晕影后处理：32x 及以上倍速跳过晕影叠加，避免性能抖动
- 移除 Canvas 的 CSS `filter` 属性（此前导致高倍速屏闪）
- 晕影效果使用缓存渐变，减少每帧绘制开销

### 1.3 Canvas 历史化绘制工具 (`ui/canvas_theme.js`)
- `CT.drawPanel()`：圆角面板 + 装饰边框 + 皮革纹理背景
- `CT.drawOrnamentLine()`：装饰性分隔线带菱形标记
- `CT.drawCloseButton()`：带 hover 态的黄铜色关闭按钮
- `CT.drawButton()`：历史风格的按钮（黄铜边框 + 纸张底色）
- `CT.drawTitleBar()`：电报风格的标题栏
- 所有 Canvas 面板统一采用圆角（`radius: 3-4px`）+ 黄铜色边框

### 1.4 加载进度条重写 (`index.html`)
- 移除原有粗笨进度条，改为细长电报风格
- 进度条加长至 400px，使用黄铜渐变
- 修复 99% 卡住问题：优化资源加载完成检测逻辑
- 加载阶段隐藏国家选择按钮，加载完成后才显示

## 二、联机模式

### 2.1 中继服务器 (`server/server.js`)
- WebSocket 服务器，端口 1914
- 房间管理：创建/加入/离开/列表/关闭
- 席位管理：选择国家、添加/移除 AI、准备状态
- 游戏开始：房主触发，自动填充未选国家为 AI，未准备玩家移除
- 消息转发：Host 广播全量快照（2.5s）+ 增量位置（200ms），客户端操作转发至 Host
- 静态文件服务：自动 Serve 前端文件，支持 `/health` 健康检查
- 心跳检测（15s）+ 过期房间清理（1h）
- 房间号生成：5 位大写字母数字混合

### 2.2 客户端模块 (`js/multiplayer.js`)
- WebSocket 连接管理：自动检测协议（ws/wss）、地址（location.host）
- 房间大厅 UI：玩家席位、AI 席位、国家选择下拉框、准备/开始/离开按钮
- 聊天系统：房间内消息广播
- 状态同步：Host 端每 2.5s 发全量快照，每 200ms 发增量位置
- 房主权限控制：仅房主可添加 AI、开始游戏、调整速度
- 消息类型枚举：CREATE_ROOM、JOIN_ROOM、SELECT_COUNTRY、ADD_AI、GAME_START 等

### 2.3 游戏核心联机集成 (`js/game_core.js`)
- 联机模式时间倍速：仅使用 1x、2x、4x、8x、16x 离散按钮
- 单机模式时间倍速：保留 2x、4x、8x、16x、32x、64x、128x 离散选项
- 两套速度系统完全独立，互不影响
- 非房主客户端速度按钮禁用且不可交互
- 联机模式下 Host 发送 `GAME_SPEED` 消息同步倍速

### 2.4 房间号输入与 IP 显示
- 连接面板新增"通过房间号加入"区域：输入框 + 加入按钮
- `doJoinByCode()` 函数：读取房间号，房间有密码则弹窗输入
- 使用 WebRTC STUN 协议自动检测本机局域网 IP
- IP 地址显示为可点击复制标签
- 房间大厅中房主可见服务器地址

### 2.5 添加 AI 按钮修复
- **问题**：房间空位按钮调用 `MP.showAddAI`，但导出 API 名为 `MP.addAI`，名称不匹配
- **修复**：按钮 `onclick` 改为 `MP.addAI`

### 2.6 输入框数字输入修复
- **问题**：游戏全局 `keydown` 监听吃掉所有键盘事件，联机面板输入框无法输入数字
- **修复**：`keydown` 事件处理开头检查 `e.target.tagName`，`INPUT`/`SELECT`/`TEXTAREA` 时跳过

## 三、性能优化

### 3.1 师团渲染优化
- 移除每个师团的 `save/restore` 对，改为手动重置属性
- 小型 emoji 不使用离屏 bitmap 缓存（浏览器原生 `fillText` + 硬件加速路径更高效）

### 3.2 投射物空间索引优化
- 仅在存在投射物时构建空间索引，无投射物时直接返回
- 索引构建中使用 `for` 循环替代展开运算符（`push(...cell)`），减少额外开销

### 3.3 城市渲染优化
- `majorCities` Set 设为模块级常量，避免每帧重建
- 缩放级别 ≤ 0.15 时跳过城市渲染
- 工厂仅在缩放级别 > 0.7（小城市级别）时显示

### 3.4 阵型连线渲染优化
- 渲染前进行 O(n) 前置检查，无阵型单位时完全跳过 O(n²) 嵌套循环

### 3.5 海军阵亡图标动画修复
- 使用 `performance.now()` 替代游戏内时间（`age`）作为动画基准
- 公式：`Math.sin(realNow / 1200 + g.x * 0.5)`
- 消除高倍速下图标抖动问题
